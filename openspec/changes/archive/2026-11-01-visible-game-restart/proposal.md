## Why
Players need an easy way to replace a game or restart a lesson without searching More.

## What Changes
- Add New game above the board in normal games and Start over in authored lessons.
- Use a confirmation panel that explains what is replaced and keeps learning progress.
- Preserve the existing personal-practice return-to-game flow.

## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `play-and-coaching`: visible reset actions and protected cancellation.

## Impact
App.svelte, board control styles, and product/design records. No storage schema change.
